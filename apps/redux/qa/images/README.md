# Redux app-config QA images

Upload the images used by the Redux QA app-config page directly into this directory.

Recommended filenames:

- `vertical-slot-1.png`
- `vertical-slot-2.png`
- `vertical-slot-3.png`
- `horizontal-2-slot-1.png`
- `horizontal-2-slot-2.png`
- `horizontal-3-slot-1.png`
- `horizontal-3-slot-2.png`
- `horizontal-3-slot-3.png`

Keep the PNG canvases consistent and use transparent backgrounds. The hosted QA page will reference them with relative paths such as `./images/vertical-slot-1.png`.
